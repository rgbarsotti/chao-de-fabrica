# Chão de Fábrica

Se o usuário pedir para instalar a fábrica, siga `INSTALAR.md`.

Para desenvolver este repositório: `payload/` é o que é copiado para a máquina do usuário e
`install.mjs` é o instalador. Rode `node --test test/fabrica.test.mjs` antes de qualquer commit.
Nenhum arquivo daqui pode conter nome de empresa, cliente, pessoa, caminho de máquina ou credencial.
